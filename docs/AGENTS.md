# AGENTS
This document defines the user roles and agents operating within the Kasir system.

## User Roles (Actors)

### 1. Cashier (Kasir)
- **Role:** Processes sales transactions.
- **Permissions:**
  - Open/Close shift register.
  - Create new transactions.
  - Apply discounts (up to a defined limit).
  - Print receipts.

### 2. Manager
- **Role:** Oversees daily operations and inventory.
- **Permissions:**
  - All Cashier permissions.
  - View daily sales reports.
  - Manage inventory (add/edit products, update stock).
  - Approve high-value discounts or refunds.

### 3. Administrator
- **Role:** System owner or IT staff.
- **Permissions:**
  - Full system access.
  - Manage user accounts and roles.
  - Configure system settings (taxes, store information, database backups).
  - Access advanced analytics.
