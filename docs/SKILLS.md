# SKILLS
This document outlines the technical skills and functionalities expected from the Kasir application.

## Core Capabilities
- **Transaction Processing:** Handle point of sale transactions, including cart management, discount application, and payment processing.
- **Inventory Management:** Track stock levels, handle product variations, and generate alerts for low inventory.
- **Reporting & Analytics:** Generate daily, weekly, and monthly sales reports, identifying top-selling items and revenue trends.
- **User Authentication:** Secure login for various roles with differentiated access.

## Technical Skills Used
- **Backend:** PHP 8+, Laravel 11.
- **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla or integrated with Blade).
- **Database:** PostgreSQL for robust transactional integrity and relational data management.
